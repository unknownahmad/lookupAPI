LOOKUPAPI is a Python desktop application for discovering, browsing, and organizing public web APIs. 

It allows users to search the APIs.guru directory by API name or provider, inspect descriptions, versions, documentation links, base URLs, and available endpoints with their HTTP methods, save APIs to a local database, remove saved entries, and view a log of recent activity. 

The project is built with Python, CustomTkinter for the graphical interface, Requests for fetching data from APIs.guru, PyMySQL and MySQL for storing saved APIs, python-dotenv for loading environment variables, and a text file for storing activity history.
